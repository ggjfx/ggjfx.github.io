专插本计算机基础与程序设计 · 零基础知识点#

适用：0基础起步 · 广东专插本专业综合课（计算机类）200分 这是你的优势科目（云计算专业天天接触），但 0 基础也要系统过一遍，考试考得细。

一、计算机基础知识（占分约30%）#

1. 进制转换（必考，必须会）#

  • 十进制 → 二进制：除2取余，倒序排列（例：13 → 1101）
  • 二进制 → 十进制：按权展开（例：1101 = 1×8+1×4+0×2+1×1 = 13）
  • 二进制 ↔ 八进制：3位一组；二进制 ↔ 十六进制：4位一组
  • 常用记忆：2⁰=1, 2¹=2, 2²=4, 2³=8, 2⁴=16, 2⁵=32, 2⁶=64, 2⁷=128, 2⁸=256, 2⁹=512, 2¹⁰=1024
  • 位(bit)是最小单位，字节(Byte)=8bit；1KB=1024B，1MB=1024KB，1GB=1024MB

2. 计算机组成（冯·诺依曼）#

  • 五大部件：运算器、控制器、存储器、输入设备、输出设备
  • 运算器+控制器 = CPU（中央处理器）
  • 存储器分：内存（RAM断电丢失/ROM断电保留）和外存（硬盘、U盘，断电不丢）
  • 存储程序控制：程序和数据都存内存，这是冯·诺依曼思想核心

3. 操作系统基础#

  • 作用：管理 CPU、内存、文件、设备
  • 常见概念：进程（运行中的程序）、线程、文件系统（NTFS/FAT32）、Windows/Linux

4. 网络基础（云计算专业重点）#

  • OSI七层（记口诀"物数网传会表应"）：物理、数据链路、网络、传输、会话、表示、应用
  • TCP/IP四层：网络接口、网际（IP）、传输（TCP/UDP）、应用（HTTP/FTP/DNS）
  • 常用协议：HTTP（网页）、HTTPS（加密网页）、FTP（传文件）、DNS（域名→IP）、TCP（可靠连接）、UDP（快但不保证到达）
  • IP地址：IPv4 四段点分十进制，如 192.168.1.1；A/B/C 类判断（A:1-126, B:128-191, C:192-223）
  • 云计算的三种服务模式：IaaS（基础设施，如云服务器）、PaaS（平台，如数据库服务）、SaaS（软件，如在线文档）

二、C 语言基础（占分约70%，重点）#

1. 程序结构#

#include <stdio.h>      // 头文件
int main() {            // 主函数，程序入口
    printf("Hello");    // 输出
    return 0;           // 返回
}

2. 数据类型#

类型占用例子
int 整型4字节1, -5, 100
float 单精度4字节3.14f
double 双精度8字节3.14159
char 字符型1字节‘a’, ‘1’（单引号）
字符串字符数组“hello”（双引号）

3. 运算符（必考优先级）#

  • 算术：+ − * / %（%是取余，如 7%3=1）
  • 关系：> < >= <= ==（等于）!=（不等于）
  • 逻辑：&&（且）||（或）!（非）
  • 赋值：= += −= *= /=
  • 自增自减：i++（先取值后加1）++i（先加1后取值）——经典易错点
  • 优先级记忆：括号 > 算术 > 关系 > 逻辑 > 赋值

4. 三大结构（程序设计的灵魂）#

① 顺序结构：从上到下执行

② 选择结构

if (score >= 60) {
    printf("及格");
} else if (score >= 80) {
    printf("优秀");
} else {
    printf("不及格");
}
  • switch 语句：多分支选择，记得每个 case 后加 break

③ 循环结构

// for 循环（最常用）
for (int i = 1; i <= 10; i++) {
    printf("%d ", i);
}

// while 循环
int i = 1;
while (i <= 10) {
    printf("%d ", i);
    i++;
}

// do-while：至少执行一次
int i = 1;
do {
    printf("%d ", i);
    i++;
} while (i <= 10);

5. 数组（必考）#

int a[5] = {1, 2, 3, 4, 5};   // 下标从0开始：a[0]~a[4]
// 求最大值
int max = a[0];
for (int i = 1; i < 5; i++) {
    if (a[i] > max) max = a[i];
}
  • 字符数组存字符串，用 strcpy/strlen/strcmp 处理（需 #include <string.h>）

6. 函数#

// 定义：返回值类型 函数名(参数) { 函数体 }
int add(int x, int y) {
    return x + y;
}
// 调用
int s = add(3, 5);   // s = 8
  • 形参（定义时的参数）和实参（调用时的参数）
  • 数组作参数：传的是地址（值会真的改）

7. 指针（难点，但专插本考得不深）#

  • 指针 = 存地址的变量
int a = 10;
int *p = &a;    // p 指向 a 的地址
printf("%d", *p);  // *p 取 a 的值 = 10
  • 记住两个符号：& 取地址，* 取内容

8. 结构体#

struct Student {
    char name[20];
    int age;
};
struct Student s = {"张三", 18};
printf("%s", s.name);

三、必背代码模板（背下来，考试直接套）#

  1. 求和：1+2+…+n → for 循环累加
  2. 求最大值/最小值：打擂台法（先假设第一个最大，逐个比）
  3. 判断素数：for 循环从 2 到 √n 看能否整除
  4. 冒泡排序（必考）：
for (int i = 0; i < n-1; i++) {
    for (int j = 0; j < n-1-i; j++) {
        if (a[j] > a[j+1]) {          // 从小到大排
            int t = a[j]; a[j] = a[j+1]; a[j+1] = t;
        }
    }
}
  1. 判断闰年：能被4整除且不能被100整除，或能被400整除
  2. 斐波那契数列：f(n)=f(n-1)+f(n-2)

四、学习建议#

  1. 先在电脑装个编译器（Dev-C++ 或 VS Code），每学一个知识点就敲一遍代码
  2. 进制转换每天练 5 题，手算
  3. 程序阅读题是专插本常考题型：会"人肉执行"代码（一步步写出变量变化）比会写更重要
  4. 你本专业课程会覆盖大部分内容，上课跟紧，考前刷真题

金句：编程不是看会的，是敲会的。 每天 30 分钟敲代码，比看 3 小时视频有用。
