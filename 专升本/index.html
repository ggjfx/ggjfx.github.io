指数/对数运算法则：aᵐ·aⁿ=aᵐ⁺ⁿ、(aᵐ)ⁿ=aᵐⁿ、logₐ(MN)=logₐM+logₐN、logₐ(M/N)=logₐM−logₐN、logₐMⁿ=n·logₐM 因式分解：a²−b²=(a+b)(a−b)、a²±2ab+b²=(a±b)²（求极限化简常用） 一、极限（第一章核心） 1. 概念 lim f(x) 表示 x 趋近某值时函数趋近的值 极限存在 ⇔ 左极限 = 右极限 2. 求极限的 5 种方法（必背套路） 直接代入（最简单，先试） 因式分解约分：如 lim (x²−1)/(x−1) = lim (x+1) = 2（x→1 时） 除以最高次幂（x→∞ 时）：分子分母同除 x 的最高次 两个重要极限： ① lim (sin x)/x = 1（x→0） ② lim (1+1/x)ˣ = e（x→∞）或 lim (1+x)^(1/x) = e（x→0） 等价无穷小替换（x→0 时）： sin x ~ x，tan x ~ x，ln(1+x) ~ x，eˣ−1 ~ x，1−cos x ~ x²/2 3. 无穷小与无穷大 无穷小：极限为 0 的量；无穷小 × 有界函数 = 无穷小（常考） 4. 连续性 f(x) 在 x₀ 连续 ⇔ 左极限=右极限=f(x₀) 间断点分类：第一类（左右极限都存在：可去/跳跃）、第二类（无穷/振荡） 乘积：(uv)’ = u’v + uv' 商：(u/v)’ = (u’v − uv’)/v² 复合函数（链式法则，必考）：y=f(g(x))，则 y’ = f’(g(x))·g’(x) 例：(sin 2x)’ = cos 2x · 2 = 2cos 2x 隐函数求导：方程两边同时对 x 求导，把 y 当函数，解出 y' 高阶导数：就是导数的导数，f’’(x) 4. 微分 dy =
