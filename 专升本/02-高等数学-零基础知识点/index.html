专插本高等数学 · 零基础知识点#

适用：中职/0基础起步 · 广东专插本专业基础课（计算机类）100分 好消息：专插本高数只考一元微积分（函数→极限→导数→积分），不考级数、多元函数、微分方程大题，比考研简单很多。

〇、预备知识（0基础先补这些）#

  • 集合：交集 ∩、并集 ∪、区间写法 [1,2)、(1,+∞)
  • 函数：定义域、值域、f(x) 的含义
  • 基本初等函数（必须会画图）：
    • 幂函数 y=x², y=x³, y=1/x
    • 指数函数 y=aˣ（a>0且a≠1）
    • 对数函数 y=logₐx（与指数互为反函数）
    • 三角函数 sin x, cos x, tan x（记住 0° 30° 45° 60° 90° 的函数值）
    • 反三角函数 arcsin x, arctan x（会查表即可）
  • 指数/对数运算法则：aᵐ·aⁿ=aᵐ⁺ⁿ、(aᵐ)ⁿ=aᵐⁿ、logₐ(MN)=logₐM+logₐN、logₐ(M/N)=logₐM−logₐN、logₐMⁿ=n·logₐM
  • 因式分解：a²−b²=(a+b)(a−b)、a²±2ab+b²=(a±b)²（求极限化简常用）

一、极限（第一章核心）#

1. 概念#

  • lim f(x) 表示 x 趋近某值时函数趋近的值
  • 极限存在 ⇔ 左极限 = 右极限

2. 求极限的 5 种方法（必背套路）#

  1. 直接代入（最简单，先试）
  2. 因式分解约分：如 lim (x²−1)/(x−1) = lim (x+1) = 2（x→1 时）
  3. 除以最高次幂（x→∞ 时）：分子分母同除 x 的最高次
  4. 两个重要极限：
    • ① lim (sin x)/x = 1（x→0）
    • ② lim (1+1/x)ˣ = e（x→∞）或 lim (1+x)^(1/x) = e（x→0）
  5. 等价无穷小替换（x→0 时）：
    • sin x ~ x，tan x ~ x，ln(1+x) ~ x，eˣ−1 ~ x，1−cos x ~ x²/2

3. 无穷小与无穷大#

  • 无穷小：极限为 0 的量；无穷小 × 有界函数 = 无穷小（常考）

4. 连续性#

  • f(x) 在 x₀ 连续 ⇔ 左极限=右极限=f(x₀)
  • 间断点分类：第一类（左右极限都存在：可去/跳跃）、第二类（无穷/振荡）

二、导数与微分（第二章核心）#

1. 导数定义#

  • f’(x₀) = lim [f(x₀+h)−f(x₀)]/h（h→0）
  • 几何意义：切线斜率

3. 求导法则#

  • 和差：(u±v)’ = u’±v'
  • 乘积：(uv)’ = u’v + uv'
  • 商：(u/v)’ = (u’v − uv’)/v²
  • 复合函数（链式法则，必考）：y=f(g(x))，则 y’ = f’(g(x))·g’(x)
    • 例：(sin 2x)’ = cos 2x · 2 = 2cos 2x
  • 隐函数求导：方程两边同时对 x 求导，把 y 当函数，解出 y'
  • 高阶导数：就是导数的导数，f’’(x)

4. 微分#

  • dy = f’(x)dx（常考选择题：求微分）

三、导数应用（第三章）#

  1. 洛必达法则：0/0 或 ∞/∞ 型极限，分子分母分别求导再求极限
  2. 单调性：f’(x)>0 递增，f’(x)<0 递减
  3. 极值：f’(x)=0 的点（驻点）处，左正右负→极大值；左负右正→极小值
  4. 最值：闭区间上，比较所有极值点和端点函数值
  5. 凹凸性与拐点：f’’(x)>0 凹（开口向上），f’’(x)<0 凸；f’’(x)=0 且变号→拐点

四、不定积分（第四章）#

1. 概念#

  • ∫f(x)dx = F(x)+C，其中 F’(x)=f(x)（求导的逆运算，别忘了 +C！）

2. 基本积分公式（与导数表对应背）#

积分结果
∫xⁿdxxⁿ⁺¹/(n+1) + C
∫1/x dxln
∫eˣdxeˣ + C
∫sin x dx−cos x + C
∫cos x dxsin x + C
∫1/(1+x²)dxarctan x + C

3. 两大方法（必考）#

  • 第一换元法（凑微分）：∫f(g(x))·g’(x)dx = ∫f(u)du，令 u=g(x)
    • 例：∫2x·e^(x²)dx，令 u=x²，du=2xdx → ∫eᵘdu = e^(x²)+C
  • 分部积分：∫u dv = uv − ∫v du（适用于 ∫x·eˣ、∫x·sin x 型，“反对幂指三"优先选 u）

五、定积分（第五章）#

1. 概念与牛顿-莱布尼茨公式（核心）#

  • ∫ₐᵇ f(x)dx = F(b) − F(a)（F 是 f 的原函数）

2. 定积分性质（常考小题）#

  • ∫ₐᵇ k·f(x)dx = k∫ₐᵇ f(x)dx
  • 奇函数在对称区间 [−a,a] 上积分为 0；偶函数 = 2∫₀ᵃ
  • 比较大小：f(x)≥g(x) 则积分也≥

3. 应用：求平面图形面积#

  • S = ∫ₐᵇ [上曲线−下曲线] dx（先画图，找交点定上下限）

六、专插本高数考情提示#

  • 题型：单选+填空+计算题+综合题，计算题占大头，步骤分很重要，写清楚过程
  • 高频考点：求极限（必考）、求导、不定积分/定积分计算、单调区间与极值
  • 复习顺序：先背熟两张表（求导公式表、积分公式表），再刷真题

金句：高数 = 公式表 × 刷题量。 公式不熟一切白搭，每天默写一遍公式表。
