    Linux 基础命令大总结

    第一次总结：我学到了什么？ ______ 📋 我学到了什么？ 🐧 Linux 基础命令（16 个核心指令） 目录导航类 pwd：打印当前工作目录，就像抬头看楼层指引牌，确认"我在哪儿" ls：列出当前目录下的文件和文件夹，就像探头看鞋柜里有什么；-l 看详情，-a 看隐藏文件，-h 让大小人类可读 cd：切换目录，就像在办公楼里换房间；.. 回到上层，/ 回到根目录，~ 回到家目录，- 回到上次的目录 ~：当前用户的家目录快捷方式，root 的 ~ 是 /root，普通用户是 /home/用户名 文件管理类 mkdir：创建文件夹，-p 可以一次性创建多层目录 cp：复制文件或文件夹，-r 复制文件夹，-i 覆盖前询问 mv：移动文件，或者在同一目录下重命名 内容操作类 cat：查看小文件内容，或者配合 < echo：输出文字，配合 > 覆盖写入文件，» 追加写入文件 ：重定向符号，把输出写到文件里（覆盖） ：重定向符号，把输出追加到文件末尾 查找与过滤类 grep：在文件内容里搜索关键词，-r 递归搜目录，-i 忽略大小写，-n 显示行号，-v 反向匹配 find：在文件系统里搜索文件，-name 按名字，-type 按类型，-mtime 按修改时间，-size 按大小 权限与运行类 ls -l：查看文件权限详情，就像看文件的"身份证" chmod +x：给文件添加可执行权限，就像给门禁卡激活 ./：指定"在当前目录下"运行某个文件 用户切换类 su -：切换到另一个用户（默认 root），- 表示同时加载目标用户的环境变量 exit：退出当前用户，回到切换前的用户 网络与排障类 ping：测试网络连通性，就像喊一嗓子看对面答不答应；-c 指定次数 curl：像浏览器一样访问网址，-o 下载保存为指定文件名，-O 用原文件名保存，-I 只看响应头 sed：流编辑器，批量替换文本，s/旧/新/g 是替换语法，-i 直接改原文件 yum：CentOS 的软件包管理器，就像系统里的"应用商店"；install 安装，remove 卸载，makecache 刷新缓存 环境配置类 ...
