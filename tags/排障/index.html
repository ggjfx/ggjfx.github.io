Linux系统安装后没拿到 IP 地址,所以上不了网

📝 第一次输出：我学到了什么？ 这次网络排障，你实际上掌握了一套完整的网络排障方法论，而不仅仅是几个命令。来，我们把知识点分类列出来： 【计算机网络基础】 DNS（域名系统）的本质：它是互联网的“电话本”，把人类好记的域名（如 baidu.com）翻译成机器能识别的 IP 地址。报错 Name or service not known 就是查不到这个电话本。 IP 地址的概念：互联网上每台设备的“门牌号”。8.8.8.8 是 Google 的公共 DNS 服务器地址，常被用作网络连通性测试的目标。 网络不可达（Network Unreachable）的含义：数据包在本地网络就迷路了，根本没踏上通往互联网的路。这通常意味着网关缺失或物理连接有问题。 排障的“分层思维”：从物理层（网线/WiFi）→ 网络层（IP地址）→ 传输层（路由/网关）→ 应用层（DNS），一层一层往上查，这是网络工程师最核心的思维方式。 【Linux 系统管理】 sudo 和 sudoers 文件：sudo 是“临时借用管理员权限”的命令，但只有被列入 /etc/sudoers 文件的用户才能使用。报错 not in the sudoers file 说明你的账户没有被授权。 su - 命令的正确用法：su - 是“完全切换用户身份”，包括环境变量。- 这个横杠很重要，没有它你可能连 PATH 都加载不全。 root 用户的权限边界：root 是系统的“超级管理员”，可以做任何事情，但也意味着“手滑一下系统就崩了”。所以平时用普通用户，必要时才切 root。 【Linux 网络排障命令】 ip route 命令：查看路由表，相当于看“出门地图”。如果输出为空，说明没有默认网关，数据包不知道往哪儿送。 ip addr 命令：查看网卡信息和 IP 地址，相当于看“自家的门牌号和门锁状态”。 dhclient 命令：手动向路由器申请 IP 地址，相当于“拿着身份证去物业登记，领一张门禁卡”。 ping 命令的高级用法：ping 8.8.8.8 测试网络连通性，ping baidu.com 测试 DNS 解析。两者结合能快速定位问题出在哪一层。 ...
