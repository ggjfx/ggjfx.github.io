🛠️ 运维工程师基础学习资料#

🎯 面向零基础 / 刚入门，按学习顺序整理 学完这份路线，可继续进阶 K8s、CI/CD、自动化运维。

🧭 学习路线总览#

🔹 Linux 命令 → 🌐 网络 → 🐚 Shell 脚本 → 🌍 Nginx/Web
→ 🗄️ 数据库 → 🐳 Docker → 🌿 Git → 📊 监控 → ☁️ 云计算

1️⃣ 操作系统基础（⭐ 最核心）#

🐧 Linux（必学）#

Ubuntu / CentOS / Rocky Linux 任选一种上手

分类命令
📁 文件与目录ls cd cp mv rm mkdir find
✏️ 查看与编辑cat less vim
🔐 权限管理chmod chown chgrp、用户与组
⚙️ 进程管理ps top htop kill
🌐 网络ip ss ping curl
🔗 软链接ln -s
⏰ 定时任务cron

📚 推荐书籍： 《鸟哥的 Linux 私房菜》（经典中文入门）

💡 练习建议： 装个虚拟机（VirtualBox / VMware）或云服务器，反复实操折腾。

2️⃣ 计算机网络 🌐#

  • 🧱 OSI 七层模型 / TCP-IP 四层模型
  • 🔑 核心协议： TCP/UDP、HTTP/HTTPS、DNS、DHCP
  • 🧰 排查工具： curl telnet nslookup ping traceroute
  • 🔍 抓包分析： tcpdump、Wireshark

3️⃣ Shell 脚本编程 🐚#

  • Bash 语法： 变量、条件判断、循环、函数
  • 常用命令： grep sed awk、管道、重定向

🎯 目标： 能写脚本自动化日常运维任务（备份、日志清理、批量操作）

4️⃣ 服务器与 Web 服务 🌍#

  • ⚡ Nginx / Apache： 配置、反向代理、负载均衡、虚拟主机
  • 🖥️ 常见服务： SSH、FTP、邮件服务
  • 📝 网站发布、日志管理与轮转

5️⃣ 数据库基础 🗄️#

🐬 MySQL / PostgreSQL#

  • ✅ 基本增删改查（SQL）
  • 💾 备份与还原
  • 👤 用户与权限管理

⚡ Redis（缓存 · 进阶）#

6️⃣ 虚拟化与容器 🐳（现代运维必备）#

Docker#

  • 📦 镜像、容器、Dockerfile、docker-compose
  • 💽 数据卷、网络、端口映射

虚拟机技术基础#

  • 🖥️ KVM / VMware

7️⃣ 版本控制 🌿#

Git#

  • 🔀 提交、分支、合并、回滚
  • ☁️ 远程仓库：GitHub / Gitee

8️⃣ 监控与日志 📊#

基础#

  • 🧾 系统日志：journalctl、/var/log
  • ⚡ 性能查看：uptime top free df iostat

入门后可学#

  • 📈 Prometheus + Grafana
  • 🛡️ Zabbix

9️⃣ 云计算基础 ☁️#

  • 主流平台： 阿里云 / 腾讯云 / AWS
  • 核心概念： ECS（云服务器）、负载均衡 SLB、对象存储 OSS、RDS（云数据库）
  • 可选认证： 阿里云 ACA / AWS Certified Architect

🔟 常用编程语言（辅助）💻#

  • 🐍 Python（强烈推荐）：脚本、自动化、爬虫、运维工具开发
  • 🦫 Go（进阶）：容器与 K8s 生态常用

🚀 后续进阶方向#

方向技术
容器编排⚓ Kubernetes（K8s）
CI/CD🔄 Jenkins / GitLab CI
IaC 自动化🏗️ Ansible / Terraform
自动化平台🤖 运维自动化平台

💡 本资料为入门整理，可根据个人基础调整顺序与深度。
