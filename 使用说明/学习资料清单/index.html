网络运维工程师 · 学习资料包清单#

整理日期：2026-08-13 本包内全部为官方/作者免费授权的电子书与文档，可放心学习使用。

📦 本包已包含的文件#

0. 《An Introduction to Computer Networks》(计算机网络导论) —— 基础入门首选#

  • 文件：dordal-intro-networks.pdf（7.2MB）+ dordal-intro-networks.epub（4.7MB）
  • 作者：Peter L. Dordal（Loyola University Chicago），开放许可，免费
  • 内容：从零开始的计算机网络入门教材——以太网、IP 寻址、子网、路由、TCP/UDP、DNS、HTTP，大量配图和示例，比 CNP3 更浅显，适合零基础起步
  • 官网：https://intronetworks.cs.luc.edu

1. 《Computer Networking: Principles, Protocols and Practice》(CNP3)#

  • 文件：CNP3-2021.pdf（7.8MB）+ CNP3-2021.epub（1.1MB，适合手机阅读器）
  • 作者：Olivier Bonaventure（UCLouvain 教授），开放许可（CC BY-SA）
  • 内容：计算机网络原理与协议实践，从应用层到底层全覆盖，含大量抓包实验，是 TCP/IP 理论的优秀免费替代教材
  • 官网：https://www.computer-networking.info

2. 《Wireshark User’s Guide》官方用户指南#

  • 文件：Wireshark_User_Guide.pdf（15.2MB）
  • 来源：Wireshark 官方文档（免费）
  • 内容：Wireshark 全功能使用手册——抓包、过滤器、统计、协议分析，网络运维排查故障的必备工具书

3. 《Linux Network Administrator’s Guide》(Linux 网络管理员指南)#

  • 文件：Linux_Network_Administrators_Guide.pdf（1.6MB）
  • 来源：The Linux Documentation Project（TLDP，免费）
  • 内容：Linux 网络管理经典入门：网络配置、路由、防火墙、DHCP/DNS 服务搭建——运维必备的 Linux 基础

4. RFC 1180《A TCP/IP Tutorial》(TCP/IP 入门教程)#

  • 文件：rfc1180-tcpip-tutorial.txt（62KB）
  • 来源：IETF 官方 RFC（免费）
  • 内容：一份简洁的 TCP/IP 协议族入门教程，一小时能读完，适合打基础

🗺️ 建议学习顺序#

  1. 打基础：RFC 1180 教程 → 《图解TCP/IP》（可买）→ B站计算机网络微课堂
  2. 学理论：CNP3 教材（本包）→ 《TCP/IP详解卷1》（可买）
  3. 练工具：Wireshark 指南（本包）→ 装 Wireshark 抓包实战
  4. 上系统：Linux 网络管理员指南（本包）→ 装个 Linux 虚拟机练配置
  5. 考证书：华为人才在线学 HCIA → eNSP 练模拟 → 考 HCIP
  6. 刷题：软考网络工程师真题（历年题库网上有免费版）
