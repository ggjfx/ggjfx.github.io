🦐 博客使用与维护指南#

基于 Hugo + PaperMod 的个人博客,Obsidian 写笔记,GitHub Pages 托管。 最后更新:2026-08-12

一、博客概况#

项目内容
线上网址https://ggjfx.github.io/
网站标题YH-C
GitHub 账号ggjfx
站点根目录D:\my-Blog(Hugo 根)
Obsidian 笔记库D:\my-Blog\my-Blog(内容源)
主题PaperMod(奶油暖色系定制)
本地预览http://127.0.0.1:1313/

二、目录结构(文件地图)#

D:\my-Blog\
├── hugo.toml                 网站主配置(标题/菜单/参数)
├── deploy.ps1                一键发布脚本
├── 打开博客.bat              双击打开线上博客(桌面有副本)
├── 本地预览.bat              双击启动本地预览(桌面有副本)
├── assets\css\extended\custom.css   主题样式(奶油色系/响应式/所有 UI 定制)
├── layouts\                 自定义模板
│   ├── index.html               新版首页(英雄区+最新3篇)
│   ├── 404.html                 自定义404页
│   ├── _default\terms.html      标签分组页
│   └── _partials\
│       ├── header.html          覆盖主题头部(修复菜单跳转)
│       ├── post_nav_links.html  上一篇/下一篇(自定义)
│       └── extend_footer.html   页脚附加(本地链接修复JS)
├── i18n\zh-cn.yaml          中文翻译补充
├── public\                  构建产物(部署用,可随时重建)
└── my-Blog\                 ← Obsidian 库(写文章的地方!)
    ├── _index.md                首页"关于我"介绍(可在 Obsidian 直接编辑)
    └── posts\                   文章都放这里
        ├── _index.md            "文章"列表页标题
        └── 你的文章.md

⚠️ 永远不要改 themes\PaperMod\ 里的东西(主题本体,更新会被覆盖)。要定制就在站点目录建同名文件覆盖。

三、日常使用流程(三步)#

1. 写文章#

在 Obsidian 里新建笔记,放进 posts 文件夹,文件头加「身份证」:

---
title: 文章标题
date: 2026-08-12T12:00:00+08:00
draft: false
tags:
  - Linux
---

## 正文用标题层级(## / ### / ####)
目录会自动生成,长文必备

2. 预览(可选)#

双击桌面 本地预览.bat → 自动开浏览器到 http://127.0.0.1:1313/

关掉黑色窗口 = 停止预览

3. 发布#

双击…不,发布用 PowerShell:

powershell -ExecutionPolicy Bypass -File D:\my-Blog\deploy.ps1

或直接说"发布",由助手代跑。等 1 分钟,打开 https://ggjfx.github.io/ 按 Ctrl+F5 查看。

五、踩过的坑(重要经验)#

  1. SRI 校验导致线上无样式:git 推送时换行符 CRLF→LF,文件字节变了,浏览器 SRI 校验失败拒收 CSS。 解决:hugo.toml 里 [params.assets] disableFingerprinting = true。 ⚠️ 该配置必须放在 hugo.toml 末尾,放中间会把 contentDir 等键吞掉导致文章全丢!

  2. 本地预览点文章跳云端:Hugo 用 baseURL 生成绝对链接(指向线上)。 解决:本地预览必须加参数 → hugo server --baseURL http://127.0.0.1:1313/(bat 已内置)。

  3. 顶部菜单跳云端:主题强制 absLangURL。已通过覆盖 header.html 改为相对路径根治。

  4. bat 文件打不开:bat 里不能写中文(编码乱码会破坏命令),已全部改英文。

  5. 手机看到旧样式:CSS 无版本号,手机浏览器缓存严重。 → 手机测试一律用无痕窗口。

  6. localhost 拒绝连接:预览服务器只监听 IPv4,用 http://127.0.0.1:1313/ 而不是 localhost。

  7. 网络环境:Watt Toolkit(Steam++)加速 GitHub;命令行工具需 git config --global http.sslBackend schannel + http.schannelCheckRevoke false,curl 加 --ssl-no-revoke。

六、常用命令速查#

# 本地预览(带参数,防止跳云端)
cd D:\my-Blog
hugo server --baseURL http://127.0.0.1:1313/

# 发布
powershell -ExecutionPolicy Bypass -File D:\my-Blog\deploy.ps1

# 手动构建(不发布)
hugo --minify --destination D:\my-Blog\public
