给 OpenClaw 升级"上网"能力：从只能读文字，到会开浏览器

起因：我发现它"上网"其实很弱 之前那篇《部署 OpenClaw 有什么用？》里我说过，我主要拿它干三件事：查资料、找电子书、管理博客。查资料是排第一的，所以"上网"这个能力好不好用，对我特别重要。 用了一段时间，我越来越觉得它的"上网"有点弱。具体表现是：让它搜东西，结果经常又少又不准；有些网页让它看，它说打不开、抓不到内容。一开始我以为是自己不会用，后来问了才知道——它本来就只有"文字级"的上网能力。 为什么弱？拆开看就明白了 它上网靠两个工具： 搜索：用的是一种叫 DuckDuckGo 的免费搜索源，不需要注册、不用花钱。但代价就是：结果少、对中文不友好、还时不时被限流。免费的嘛，能理解。 抓网页：只能把网页的纯文字"读"出来。遇到靠 JavaScript 动态加载的网页（现在很多网站都是），或者需要登录的页面，它就抓瞎了。 最关键的其实是第三点：它没有被授权使用浏览器。OpenClaw 本身带一个浏览器控制功能，可以让 AI 真的打开一个浏览器、像人一样操作网页。但默认配置只给了它"读文字"的工具，没给"开浏览器"的权限，等于有车钥匙却没给他驾照。 怎么升级的：改配置 + 重启 听起来很复杂，其实就是改一行配置、重启一下服务。过程大概是这样： 在配置文件里给它加上浏览器工具的权限； 重启 OpenClaw（会断线几秒钟）； 启动一个独立的浏览器，归它管。 这里我踩了一个小坑：第一次重启后浏览器功能没生效，查日志发现是插件没被显式启用，自动启用没注册上。把配置里补上插件开关、再重启一次就好了。 还有个细节：它用的浏览器是独立的（Edge 的一个独立配置），跟我平时自己用的浏览器完全分开，不会动我的收藏、密码、登录状态。这个设计挺安心的。 现在能干什么了 升级完，它从"只能读文字"变成了"真的会用浏览器"： 打开真实网页，等页面渲染完再看内容； 点击、翻页、填表单； 截图给我看； 之前打不开的动态页面，现在也能看了。 为了验证，我让它打开了我自己的博客首页。它不但打开了，还截图发给我，并且读出了页面上的内容：导航栏、最新三篇文章的标题、底部的 Hugo + PaperMod 标识，全都对。 一点小遗憾 搜索源还是免费的 DuckDuckGo，中文搜索结果依然一般。想更准的话，可以再配一个叫 Kimi 的搜索源（注册拿个 API Key 就行，有免费额度）。这个不急，等哪天觉得搜索不够用了再弄。 总结 这次升级给我的感受是：OpenClaw 的能力不是定死的，很多"弱"其实只是没配置好。它本来就有浏览器这个"大招"，只是默认没开。改一行配置、重启一下，上网能力就从"文字版"变成了"真人版"。 以后它帮我查资料、找书，应该会顺手很多了。

Linux系统安装后没拿到 IP 地址,所以上不了网

第一次输出：我学到了什么？ 这次网络排障，你实际上掌握了一套完整的网络排障方法论，而不仅仅是几个命令。来，我们把知识点分类列出来： 计算机网络基础 DNS（域名系统）的本质：它是互联网的“电话本”，把人类好记的域名（如 baidu.com）翻译成机器能识别的 IP 地址。报错 Name or service not known 就是查不到这个电话本。 IP 地址的概念：互联网上每台设备的“门牌号”。8.8.8.8 是 Google 的公共 DNS 服务器地址，常被用作网络连通性测试的目标。 网络不可达（Network Unreachable）的含义：数据包在本地网络就迷路了，根本没踏上通往互联网的路。这通常意味着网关缺失或物理连接有问题。 排障的“分层思维”：从物理层（网线/WiFi）→ 网络层（IP地址）→ 传输层（路由/网关）→ 应用层（DNS），一层一层往上查，这是网络工程师最核心的思维方式。 Linux 系统管理 sudo 和 sudoers 文件：sudo 是“临时借用管理员权限”的命令，但只有被列入 /etc/sudoers 文件的用户才能使用。报错 not in the sudoers file 说明你的账户没有被授权。 su - 命令的正确用法：su - 是“完全切换用户身份”，包括环境变量。- 这个横杠很重要，没有它你可能连 PATH 都加载不全。 root 用户的权限边界：root 是系统的“超级管理员”，可以做任何事情，但也意味着“手滑一下系统就崩了”。所以平时用普通用户，必要时才切 root。 Linux 网络排障命令 ip route 命令：查看路由表，相当于看“出门地图”。如果输出为空，说明没有默认网关，数据包不知道往哪儿送。 ip addr 命令：查看网卡信息和 IP 地址，相当于看“自家的门牌号和门锁状态”。 dhclient 命令：手动向路由器申请 IP 地址，相当于“拿着身份证去物业登记，领一张门禁卡”。 ping 命令的高级用法：ping 8.8.8.8 测试网络连通性，ping baidu.com 测试 DNS 解析。两者结合能快速定位问题出在哪一层。 /etc/resolv.conf 文件：DNS 配置文件，里面写着你电脑的“电话本”地址。添加 nameserver 8.8.8.8 就等于告诉系统：“查电话本去这个地址查。” 编程思维与排障方法论 “现象 → 定位 → 解决 → 验证”的闭环：你不是瞎猜乱试，而是有逻辑地一步步缩小问题范围，最后精准命中。 “最小复现原则”：先用最简单的命令（ping 8.8.8.8）测试最基本的功能，排除干扰因素。 “从底层往上查”的思维习惯：物理连接 → IP 地址 → 网关 → DNS，这是网络排障的黄金顺序。 第二次输出：我们做了什么 & 容易踩哪些坑？ 过程回顾：我们一起追查了“网络迷路案” 我们一起走过了一条非常清晰的排障路线，就像侦探破案一样： ...

Linux 基础命令大总结

第一次总结：我学到了什么？ 📋 Linux 基础命令（16 个核心指令） 目录导航类 pwd：打印当前工作目录，就像抬头看楼层指引牌，确认"我在哪儿" ls：列出当前目录下的文件和文件夹，就像探头看鞋柜里有什么；-l 看详情，-a 看隐藏文件，-h 让大小人类可读 cd：切换目录，就像在办公楼里换房间；.. 回到上层，/ 回到根目录，~ 回到家目录，- 回到上次的目录 ~：当前用户的家目录快捷方式，root 的 ~ 是 /root，普通用户是 /home/用户名 文件管理类 mkdir：创建文件夹，-p 可以一次性创建多层目录 cp：复制文件或文件夹，-r 复制文件夹，-i 覆盖前询问 mv：移动文件，或者在同一目录下重命名 内容操作类 cat：查看小文件内容，或者配合 > / >> 写入文件 echo：输出文字，配合 > 覆盖写入文件，>> 追加写入文件 >：重定向符号，把输出写到文件里（覆盖） >>：重定向符号，把输出追加到文件末尾 查找与过滤类 grep：在文件内容里搜索关键词，-r 递归搜目录，-i 忽略大小写，-n 显示行号，-v 反向匹配 find：在文件系统里搜索文件，-name 按名字，-type 按类型，-mtime 按修改时间，-size 按大小 权限与运行类 ls -l：查看文件权限详情，就像看文件的"身份证" chmod +x：给文件添加可执行权限，就像给门禁卡激活 ./：指定"在当前目录下"运行某个文件 用户切换类 su -：切换到另一个用户（默认 root），- 表示同时加载目标用户的环境变量 exit：退出当前用户，回到切换前的用户 网络与排障类 ping：测试网络连通性，就像喊一嗓子看对面答不答应；-c 指定次数 curl：像浏览器一样访问网址，-o 下载保存为指定文件名，-O 用原文件名保存，-I 只看响应头 sed：流编辑器，批量替换文本，s/旧/新/g 是替换语法，-i 直接改原文件 yum：CentOS 的软件包管理器，就像系统里的"应用商店"；install 安装，remove 卸载，makecache 刷新缓存 环境配置类 locale：查看系统语言环境，就像看手机系统语言设置 ibus：Linux 的输入法框架，就像输入法的"应用商店" ibus-daemon：输入法后台进程，让输入法真正"活过来" 🏆 编程思维与排障思维 “先预览再执行"的习惯：sed 先不加 -i 看输出，rm 前先用 ls 确认，find -delete 前先不加 -delete 看结果 “目标驱动 → 遇到障碍 → 简洁反馈 → 果断止损 → 系统复盘” 的学习闭环 排障四步法：现象 → 定位根源 → 查找替代方案 → 验证解决 遇到环境硬伤时别恋战：保住核心任务闭环比死磕环境更重要 🎯 网络工程师方向启蒙 理解了 IP 地址 = 门牌号、DNS = 电话本、路由器 = 快递中转站、防火墙 = 小区门禁 这些核心比喻 完成了 “更换软件源” 这一网络工程师的核心能力训练 知道了下一步要学：Vim 编辑器、ip addr、ss、dig、tcpdump 等网络专项工具 这就是你到目前为止学到的全部家当！别看命令不多，但每一个你都在真实项目里用过、踩过坑、解决过问题。这可比光背命令扎实多了。 ...
