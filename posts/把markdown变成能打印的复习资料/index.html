起因：屏幕上看着好，打出来一塌糊涂#

我在准备专升本，让 AI 帮我整理了一堆知识点，都是 Markdown。在电脑上看没问题，但我想打出来做纸质资料——一打就发现全是问题：

  • 页眉页脚带着一串文件路径和日期
  • 我特意做的"页头信息栏"只出现在第一页
  • 一道例题的题目在这一页、图跑到下一页去了
  • 数学公式里的上标下标打出来是方框
  • 字太小，看着累

折腾了几轮以后，现在这条链路稳定了，一条命令从 Markdown 出打印版 PDF 和 Word。这篇把踩过的坑记下来。

整体链路#

Markdown 源文件
  ├─→ md-to-print.js  → A4 打印版 HTML  → Edge 无头模式 → PDF
  └─→ md2docx.py（python-docx）        → Word（可编辑）

两条腿的原因：PDF 用来打印，Word 留着改。资料这种东西一定会改，只出 PDF 早晚要重做。

转换脚本我自己写的，支持三个我最需要的参数：字号缩放、装订边距、“不许分页"的块。

坑 1：Edge 无头打印的页眉页脚，要两个参数才能去掉#

命令大概是这样：

msedge --headless=new --no-pdf-header-footer --print-to-pdf-no-header --print-to-pdf="out.pdf" "in.html"

重点：--no-pdf-header-footer 和 --print-to-pdf-no-header 这两个参数都要给。

我一开始只给了 --print-to-pdf-no-header，出来的 PDF 照样带页眉页脚。查了半天以为是 CSS 的问题，其实是参数不够。两个都加上就干净了。

坑 2：必须 -Start-Process -Wait，否则文件还没生成#

PowerShell 里如果直接用 & 调用 Edge，它异步返回——脚本以为打印完了，下一步去读 PDF，文件还不存在。

Start-Process msedge -ArgumentList $args -Wait     # ✅ 一定要 -Wait

这个坑很容易伪装成"Edge 有时候能生成有时候不能”，其实是竞态。

坑 3：打印时哪些东西会每页重复？#

这条是排版的核心，我试出来的结论：

做法打印时每页重复？
position: fixed 元素❌ 不重复（只有第一页有）
body 的 background❌ 只有第一页
表格的 <thead> / <tfoot>✅ 每页都重复

也就是说，想让页头信息（标题、姓名、日期）出现在每一页，唯一可靠的办法是把它做成一个表格的 <thead>。 用 position: fixed 做浮动页头，在屏幕上完美，打印出来只有第一页有。

我的单词清单就是这么干的：整张清单是一个大表格，标题和表头放 thead 里，翻到第 5 页表头还在。

坑 4：图文分离 → 用一个"不许拆"的块#

例题的题干和配图被分到两页，是最影响阅读的问题。解决办法是给这类内容包一层：

<div class="keep">…题目 + 图…</div>

.keep { break-inside: avoid; page-break-inside: avoid; }

转换脚本支持识别这种块，自动包上。定理和它的证明、表格和表格说明，都适合这么处理。

坑 5：公式里的 Unicode 上下标会变方框#

Markdown 里为了省事，上标经常直接用 Unicode 字符（比如 x²、aₙ）。屏幕上正常，打印时字体不一定有这些字形，就变成方框（豆腐块）。

我写了个小脚本在转换前做替换：Unicode 上下标 → 真正的 <sup> / <sub> 标签。这样交给浏览器渲染，字体永远有。

坑 6：中文乱码（这个跟打印无关，但每次都遇到）#

PowerShell 5.1 读没有 BOM 的 UTF-8 脚本文件时会按 GBK 解析，脚本里的中文全变乱码，然后各种莫名其妙的报错。

固定套路：写完脚本用 Node 补一个 BOM。

fs.writeFileSync(p, '\uFEFF' + s)

另外：中文路径的 PDF 文件名，Edge 的日志里会显示成乱码，但文件本身是正常的。别被日志骗了，去文件夹里看一眼。

排版参数：给自己定死#

来回调过几次以后，这些值我固定下来了（专升本资料专用）：

  • 字号：Word 16 号；PDF/HTML 20px（缩放系数 1.6）。教材级的长文档改成 15px，不然页数爆炸
  • 行高 1.75，字间距 0.04em —— 中文阅读舒服很多
  • 通栏（不分两栏），断行合并
  • 装订边距 左侧 24mm，单面打印 —— 打完要打孔装夹子

这些都是我自己看着舒服的值，不是什么标准。但写死在脚本里这件事很重要：不然每次生成都要重新调一遍，纯浪费时间。

成果#

现在一条链跑完，一份 Markdown 出三样：

  • PDF 大字版 —— 直接送打印机
  • HTML —— 双击浏览器打开，Ctrl+P 也能打，效果跟 PDF 一样
  • Word —— 想改内容改这个

计算机那份最后扩到了 9 课 120 道例题、25 页。真拿去打了，纸质资料在手上翻的感觉，跟在屏幕上滑是完全两回事。

小结#

  • 去页眉页脚要两个参数；
  • 调 Edge 必须 -Wait；
  • 每页重复的页头只能靠表格 thead，position: fixed 不行；
  • 图文别分家：break-inside: avoid；
  • Unicode 上下标转成 <sup>/<sub>，否则打印变方框；
  • 排版参数写死在脚本里，别每次手调。
