起因：我想给它装两个插件#

用 OpenClaw 一段时间后，我开始想给它加点东西。看上了两个：

  • 一个网关看门狗（openclaw-cli）：能监控服务、挂了自动重启、还有个网页监控面板。听起来很省心。
  • 一个运维防呆技能（openclaw-ops-guardrails）：号称能规范排障流程、防止误操作。

我一个云计算专业的学生，服务动不动就挂，这两个都挺对我胃口。差点就直接装了。

但我的工作区里有一条硬规矩：装任何新技能、跑任何外部代码之前，必须先过一遍安全扫描。这条规矩是之前定的，本来我以为纯属仪式感——这次它真拦住了东西。

先说结果：两个都没装#

扫描用的是一个叫 SkillSpector 的开源工具，我给它包了一层脚本，规则很简单：风险分 > 50 就是 BLOCKED，不许装。

第一个：77 分，HIGH#

openclaw-cli 扫出来 71 项发现，总分 77/100。其中最重的三条：

  • 记忆投毒（Memory Poisoning）：代码里存在操纵 AI 记忆和状态的行为；
  • 提权 / 凭据访问：会去读 .env 这类存密钥的文件；
  • 中危一堆：跳过确认的自动决策、后台进程常驻等。

说句公道话：它是个看门狗工具，“重启服务"“常驻后台"本来就是它的本职工作，被标出来不算冤。但**“读 .env"和"改 AI 的记忆"这两条，跟看门狗没关系**。而且它是个人开发者的第三方社区包，不是官方组件——我一个新手，没能力逐行审代码，那就只能认扫描结果。

第二个：连官方仓库自己都说它可疑#

第二个更有意思。它根本不是 npm 包，是技能市场里的一个技能。我一查：

  • 市场官方的 verify 直接失败，状态是 status_not_clean；
  • 安装命令自己就拒绝执行，非要我加一个 --acknowledge-clawhub-risk（我知道有风险还是要装）参数才肯继续；
  • 官方安全审计给了两条高置信度警告：
    • 93% 置信：它的故障手册里明确教你把审批开关关掉（ask=off），而且全文没有任何防护边界提醒；
    • 90% 置信：一条排查命令直接把网关 token 明文写在命令行里，也没提醒这会泄进 shell 历史和进程列表。

杀毒引擎扫它是 64/64 干净——它不是病毒，它是在教你养成危险习惯。一个"防呆技能”，反手教我关掉防呆，这就很讽刺了。

看到这我就没兴趣了。当时我给自己的回复就三个字：都不要。

过程中踩的几个坑#

顺手记一下，都是重复劳动的来源：

  1. 扫描器直接吃 GitHub 地址会报 “target not found”。解决办法是先把包的 tarball 下到本地再扫本地目录。
  2. 扫描器"发现了风险"时退出码是 1。我的脚本一开始把非 0 当失败处理，结果风险最大的那次反而被当成"脚本挂了”。教训：永远解析 JSON 报告，别只看退出码。
  3. 它的 WARNING 输出走的是 stderr，在新版 PowerShell 里会直接触发 NativeCommandError，整个脚本红一片。得单独处理。
  4. 装扫描器本身也有坑：它依赖的 yara-python 在 Windows 上没有现成的安装包，源码编译又要装 Visual Studio 编译器。我最后是找了个预编译好的 wheel 文件塞进去的。

我从这件事里学到什么#

第一，安全门要卡在"决定装之前”，不是"装完出问题之后"。 如果我先装了，看门狗常驻后台、能读 .env、还能改它自己的记忆——出了问题我根本查不出来是哪一步坏的。

第二，“官方"这三个字要自己确认。 两个包名字里都带 openclaw，我第一反应是"官方出的吧”。实际上一个是第三方社区包，另一个是市场里个人发布的技能。名字长得像，不代表沾亲带故。

第三，最危险的不是恶意代码，是"教你关掉安全措施"的文档。 病毒扫描能查出病毒，但查不出"建议您关闭审批以提升效率"这种话。而这种话对新手的伤害更大——因为它听起来很合理，而且照做以后一切都变得更顺畅了。

第四，规矩得写成文件，别写在脑子里。 AI 助手每次会话都是新的，它不会"记得"我上次的谨慎。所以这条规则是写在工作区的规则文件里的，明确到"扫描脚本路径 + 阈值 + 被拦了要怎么做"。它每次开工都会读到，不需要我提醒。

现在的流程#

装任何东西之前，就一句话：

先扫，分数 > 50 就别装，扫描本身报错也当没通过。

报告会存成 json + markdown 落在本地，想回头看随时看。这次那两份报告我留着了——留着提醒自己，差一步就装进去了。

写在最后：我不是说这两个包的作者有恶意。它们大概只是为了方便，把安全边界让得太多了。但"方便"这个东西，在一个能读我文件、能跑我命令的 AI 助手上，代价太高。宁愿麻烦一点。
