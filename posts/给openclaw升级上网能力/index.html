给 OpenClaw 升级"上网"能力：从只能读文字，到会开浏览器

起因：我发现它"上网"其实很弱#

之前那篇《部署 OpenClaw 有什么用？》里我说过，我主要拿它干三件事：查资料、找电子书、管理博客。查资料是排第一的，所以"上网"这个能力好不好用，对我特别重要。

用了一段时间，我越来越觉得它的"上网"有点弱。具体表现是：让它搜东西，结果经常又少又不准；有些网页让它看，它说打不开、抓不到内容。一开始我以为是自己不会用，后来问了才知道——它本来就只有"文字级"的上网能力。

为什么弱？拆开看就明白了#

它上网靠两个工具：

  • 搜索：用的是一种叫 DuckDuckGo 的免费搜索源，不需要注册、不用花钱。但代价就是：结果少、对中文不友好、还时不时被限流。免费的嘛，能理解。
  • 抓网页：只能把网页的纯文字"读"出来。遇到靠 JavaScript 动态加载的网页（现在很多网站都是），或者需要登录的页面，它就抓瞎了。

最关键的其实是第三点：它没有被授权使用浏览器。OpenClaw 本身带一个浏览器控制功能，可以让 AI 真的打开一个浏览器、像人一样操作网页。但默认配置只给了它"读文字"的工具，没给"开浏览器"的权限，等于有车钥匙却没给他驾照。

怎么升级的：改配置 + 重启#

听起来很复杂，其实就是改一行配置、重启一下服务。过程大概是这样：

  1. 在配置文件里给它加上浏览器工具的权限；
  2. 重启 OpenClaw（会断线几秒钟）；
  3. 启动一个独立的浏览器，归它管。

这里我踩了一个小坑：第一次重启后浏览器功能没生效，查日志发现是插件没被显式启用，自动启用没注册上。把配置里补上插件开关、再重启一次就好了。

还有个细节：它用的浏览器是独立的（Edge 的一个独立配置），跟我平时自己用的浏览器完全分开，不会动我的收藏、密码、登录状态。这个设计挺安心的。

现在能干什么了#

升级完，它从"只能读文字"变成了"真的会用浏览器"：

  • 打开真实网页，等页面渲染完再看内容；
  • 点击、翻页、填表单；
  • 截图给我看；
  • 之前打不开的动态页面，现在也能看了。

为了验证，我让它打开了我自己的博客首页。它不但打开了，还截图发给我，并且读出了页面上的内容：导航栏、最新三篇文章的标题、底部的 Hugo + PaperMod 标识，全都对。

一点小遗憾#

搜索源还是免费的 DuckDuckGo，中文搜索结果依然一般。想更准的话，可以再配一个叫 Kimi 的搜索源（注册拿个 API Key 就行，有免费额度）。这个不急，等哪天觉得搜索不够用了再弄。

总结#

这次升级给我的感受是：OpenClaw 的能力不是定死的，很多"弱"其实只是没配置好。它本来就有浏览器这个"大招"，只是默认没开。改一行配置、重启一下，上网能力就从"文字版"变成了"真人版"。

以后它帮我查资料、找书，应该会顺手很多了。
